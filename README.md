# 💻 Laptop Price Prediction (Machine Learning Project)

## 🚀 Overview
This project is an end-to-end Machine Learning application that predicts laptop prices based on user inputs such as RAM, storage, display size, and rating.

The model is trained using real-world data and deployed using Gradio to provide an interactive user interface.

---

## 🎯 Features
- Data Cleaning & Preprocessing
- Feature Engineering
- Model Training (Random Forest)
- Model Evaluation (R² Score)
- Interactive UI using Gradio
- Real-time Predictions

---

## 🧠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Gradio

---

## 📊 Machine Learning Workflow
1. Data Collection
2. Data Cleaning (handling missing values)
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Model Deployment (Gradio)
